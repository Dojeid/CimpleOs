Falkon-OS: A 64-bit Educational Hobby Operating System

Falkon-OS is an opinionated, modern 64-bit operating system written from scratch in C and NASM assembly. It features a full custom Framebuffer Desktop GUI, dynamic Window Manager, interactive Terminal Shell, Physical & Virtual Memory Management, and hardware drivers.

🪟 Windows Setup (Windows First) 🐍 build.py Script Explained

✨ Key Features

  • 64-bit Long Mode: Bootstrapped via GRUB Multiboot into 64-bit mode with 4-level paging enabled.
  • Custom Windowing GUI: Real-time window manager supporting dragging, focus, layering, taskbar, and double buffering.
  • Hardware Drivers: VBE Framebuffer Video, PS/2 Mouse cursor, PS/2 Keyboard IRQ engine, PIT Timer, and PCI enumeration.
  • Memory Subsystem: Page Frame Allocator (PMM), Virtual Memory Manager (VMM identity mapped), and Kernel Heap (`kmalloc`/`kfree`).
  • Interactive Shell: Terminal supporting commands (`fetch`, `calc`, `theme`, `uname`, `whoami`, `sysinfo`), history, and multiple window instances.

📂 Core Subsystem Map

📄 build.py - Unified Python build & VirtualBox manager
📁 src/arch/x86_64/ - 64-bit Assembly Entry, GDT, IDT, Linker
📁 src/kernel/ - Kernel entry (`main.c`), CPUID, Shell commands, Panic handling
📁 src/mm/ - Physical Memory (PMM), Virtual Paging (VMM), Kernel Heap
📁 src/drivers/ - Video Framebuffer, VGA fallback, PS/2 Input, PCI & USB
📁 src/gui/ - Desktop background, Taskbar, Window Manager, Hardware Cursor
📁 src/lib/ - Custom C Standard Library (`printf`, `string`, `io`)

1. 🪟 Windows Setup Guide (Windows First)

Building and running Falkon-OS natively on Windows using VirtualBox and Python.

Tools Needed on Windows:

  • Python 3.8+ (From python.org — Make sure to check "Add python.exe to PATH").
  • Oracle VM VirtualBox (From virtualbox.org).
  • Git for Windows (From git-scm.com).
  • Toolchain: WSL2 Ubuntu or MSYS2 (for `nasm`, `gcc`, `make`, `grub-mkrescue`).

Step-by-Step Execution on Windows:

  1. Open Command Prompt (`cmd`) or PowerShell: 
    git clone https://github.com/Saravanan-Codez/Falkon-Os.git
cd Falkon-Os
  2. Run the singular unified Python script: 
    python build.py --vbox
  3. The script will verify your environment, compile the 64-bit kernel, generate `FalkonOS.iso`, create a VirtualBox VM named "FalkonOS", configure 512MB RAM + VMSVGA graphics, attach the ISO, and launch the virtual machine automatically!

3. ⚙️ WSL2 Setup Guide (WSL Third)

Building Falkon-OS using Ubuntu inside Windows Subsystem for Linux (WSL2).

  1. Open PowerShell as Administrator: wsl --install -d Ubuntu
  2. Launch Ubuntu from Windows Start menu and install tools: 
    sudo apt update && sudo apt install -y python3 build-essential nasm grub-pc-bin grub-common xorriso mtools
  3. Navigate to your Windows repository directory: 
    cd /mnt/d/Falkon_labs/Falkon-Os
  4. Compile the ISO image: 
    python3 build.py
  5. Launch in VirtualBox on Windows: 
    python build.py --vbox

🐍 Singular Unified Python Script (`build.py`) Explained

Understanding how build.py automates toolchain verification, kernel compilation, ISO generation, and VirtualBox VM creation.

Step-by-Step Function Breakdown:

  • check_dependencies(): Inspects your environment `PATH` for `gcc`, `nasm`, `ld`, and `grub-mkrescue`.
  • clean(): Safely removes `build/`, `isodir/`, and `FalkonOS.iso`.
  • build_iso(): Invokes the compilation pipeline (assembles assembly, compiles C files, links kernel, and runs `grub-mkrescue` to create `FalkonOS.iso`).
  • run_vbox(): Uses `VBoxManage` to automatically create a Linux 64-bit VM, assign 512MB RAM + VMSVGA graphics, mount `FalkonOS.iso` to an optical drive, and start the VM.
  • run_qemu(): Launches QEMU with `-cdrom FalkonOS.iso -m 512M -vga std`.
# Command Usage Options:
python build.py          # Compile ISO image
python build.py --vbox   # Build ISO & launch in VirtualBox (Recommended)
python build.py --qemu   # Build ISO & launch in QEMU
python build.py --check  # Check installed tool dependencies
python build.py --clean  # Clean build artifacts

📦 VirtualBox Setup (Recommended)

💡 Why VirtualBox? Falkon-OS provides full hardware PS/2 mouse cursor emulation and high-resolution VBE graphics. VirtualBox handles graphics acceleration and mouse integration seamlessly!

Manual VirtualBox Setup Steps

  1. Open VirtualBox and click New.
  2. Name: FalkonOS | Type: Linux | Version: Other Linux (64-bit).
  3. Base Memory (RAM): 512 MB | Hard Disk: Select "Do not add a virtual hard disk".
  4. Display: Set Video Memory to 16 MB and Graphics Controller to VMSVGA.
  5. Storage: Attach FalkonOS.iso to the Optical Drive.
  6. Click Start 🟢 to boot!

🧠 System Architecture Overview

Boot Sequence Lifecycle

1. GRUB Multiboot Bootloader
⬇️
2. 32-bit Assembly Entry (src/arch/x86_64/boot/boot.asm)
⬇️
3. Identity Page Tables Setup (PML4 ➔ PDPT ➔ PD ➔ PT)
⬇️
4. Enable Long Mode (IA32_EFER MSR + CR0 Paging Bit)
⬇️
5. Far Jump to 64-bit Code Segment (src/kernel/main.c)
⬇️
6. Initialize GDT, IDT Interrupts, PMM, VMM & Kernel Heap
⬇️
7. Framebuffer Graphics Init ➔ Desktop GUI ➔ Window Manager Loop

🚀 Bootloader & x86_64 Long Mode Entry

The bootloader entry point is defined in boot.asm. It defines the GRUB Multiboot header flags requesting 1024x768 32-bit color depth VBE mode.

💾 Memory Management (PMM / VMM / Heap)

1. Physical Memory Manager (PMM)

Located in src/mm/pmm.c. Tracks 4KB physical page frames using a bitset bitmap derived from the GRUB memory map.

2. Virtual Memory Manager (VMM)

Located in src/mm/vmm.c. Identity maps the first 256MB of physical RAM along with the VBE Video Framebuffer address range.

⚡ Interrupts (GDT & IDT & PIC)

Falkon-OS configures a 64-bit Global Descriptor Table (GDT) and Interrupt Descriptor Table (IDT) handling PIC remapping for PIT timer, keyboard, and mouse.

🎮 Device Drivers Overview

Includes VBE Framebuffer Video Driver, PS/2 Keyboard & Mouse Drivers, and PCI/USB bus enumeration hints.

🖥️ Desktop GUI & Window Manager

Dynamic windowing system supporting window dragging, title bars, focus management, taskbar integration, hardware cursor rendering, and theme switching.

🔧 Troubleshooting Matrix

Issue / Error Root Cause Solution
grub-mkrescue: command not found Missing GRUB ISO utilities. Install grub-pc-bin xorriso mtools (Debian/Ubuntu) or grub2-tools-extra (Fedora).
VirtualBox VM displays black screen on boot Graphics Controller misconfiguration or low VRAM. Set VM Display Graphics Controller to VMSVGA or VBoxVGA and increase VRAM to 16MB.
nasm: command not found NASM assembler is not in PATH. Install nasm via package manager (e.g. sudo apt install nasm).
Mouse cursor is not moving in VM VirtualBox USB tablet integration interfering with PS/2 mouse. In VirtualBox VM Settings ➔ System ➔ Motherboard, set Pointing Device to PS/2 Mouse.
